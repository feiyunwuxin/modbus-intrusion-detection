# 学生论文常见错误清单（老师评阅对照表）

> 配套 `main.tex` 中的 `\pitfall{}` 与 `\todo{}` 宏使用。
> 老师可在学生提交初稿后，按本清单逐项打勾定位问题。

---

## 一、整体框架层（5 类）

### P-0.1 章节逻辑断裂
**典型症状**：第 3 章讲完 A 方法，第 4 章突然讲 B 方法，看不到 A→B 的必然性。
**老师提问**："为什么必须在 A 之后才能讲 B？能否调换顺序？"
**正确做法**：每章开头用 1 段（3-5 句）说明"上一章解决了 X 问题，本章解决 Y 问题，Y 是 X 的自然延伸"。

### P-0.2 创新点缺乏量化支撑
**典型症状**："本文提出了一种新方法，实验证明该方法有效。"
**正确做法**：每个创新点必须配 ≥ 1 个量化指标：Macro-F1 提升 0.7pp / 参数量减少 90% / 推理延迟降低 1.7× 等。
**参考章节**：本文 P-1.4 已示范。

### P-0.3 贡献度（Contributions）位置错误
**典型症状**：把创新点放在第 1 章末尾，但摘要里没有对应摘要；或者放在第 6 章。
**正确做法**：
- 中文摘要末尾：3-5 句话总括贡献
- 第 1.4 节：详细展开创新点
- 第 6 章：每个创新点必须有"本章小结 → 全文总结"的二次回指

### P-0.4 论文长度失控
**典型症状**：硕士论文 30 页（太少）或 100 页（太多）。
**参考标准**：工科硕士正文（不含附录）55-75 页，附录 10-20 页。
**页数分配建议**：
| 章节 | 页数 |
|---|---|
| 第 1 章 绪论 | 8-10 |
| 第 2 章 相关工作 | 8-10 |
| 第 3 章 特征工程 | 10-12 |
| 第 4 章 TCN+SE | 15-18 |
| 第 5 章 压缩量化 | 12-15 |
| 第 6 章 总结 | 3-5 |

### P-0.5 摘要写成"引言缩写"
**典型症状**：摘要 = 第 1 章浓缩。
**正确做法**：摘要应包含 **4 段式**：
1. **背景与问题**（2-3 句）
2. **方法**（3-4 句，三段对应三大创新点）
3. **结果**（2-3 句，关键数字）
4. **意义**（1-2 句，工程价值）
**总字数**：中文 500-800 字，英文 200-300 词。

## 二、摘要与目录层（4 类）

### P-1.1 数据/事实无出处
**症状**："据统计"、"研究表明"无引用。
**处方**：所有事实必须有 `[n]` 标注，引用具体机构 + 年份 + 报告名。

### P-1.2 摘要与正文指标不一致
**症状**：摘要写"F1 = 0.8340"，正文第 4.3 节写"0.8337"。
**老师最敏感**：数据一致性 = 论文态度问题。
**处方**：所有数字从同一份实验日志/JSON 复制，禁止估算。

### P-1.3 关键词过少或不当
**症状**：关键词只有 3 个，或堆砌通用词（"机器学习"、"深度学习"）。
**正确做法**：5-8 个关键词，3 个核心方法词 + 2 个应用领域词 + 1-3 个技术细节词。
**本文关键词示例**：SCADA；入侵检测；时序卷积网络；模型压缩；混合精度量化；嵌入式部署

### P-1.4 目录章节编号错误
**症状**：章用阿拉伯数字"第 1 章"，节又用中文"第一节"，混用。
**正确做法**：统一规则——章、节用阿拉伯数字（1.1, 1.2），小节用 1.1.1。
**本模板规则**：章 `\chinese{chapter}`、节 `\chinese{section}`、小节 `\arabic{subsection}`。

## 三、第 1 章 绪论层（6 类）

### P-1.5 创新点对应关系模糊
**症状**：摘要说"三大创新点"，但第 1.4 节只列了两点；或与后文章节不对应。
**处方**：
- 每个创新点必须标注 "（对应第 X 章）"
- 第 X 章开头必须有"本章对应创新点 N"

### P-1.6 创新点表述"虚大空"
**症状**："首次"、"首创"、"突破性"、"国际领先"。
**老师红线**：所有"首次/首创"必须有引文支撑，否则视为学术不端。
**正确表述**："据本文所知，本文是首个系统研究 SCADA 时序数据上 TCN-SE 架构的工作。"

### P-1.7 背景写得像教科书
**症状**：用 3 页讲什么是 SCADA、什么是深度学习。
**处方**：背景 ≤ 1.5 页，假设读者已具备本科水平。

### P-1.8 文献综述堆砌无评价
**症状**："A 提出了 ... \cite{a}，B 提出了 ... \cite{b}，C 改进了 ... \cite{c}。"
**处方**：每段文献末尾必须有 1-2 句评价，指出该方法不足，引出本文动机。
**本文示范**：P-1.2 处已示范。

### P-1.9 "现有研究不足"凑数
**症状**：列出 5 条不足，但后文只解决了 2 条。
**处方**：不足的数量 ≤ 创新点的数量 + 1。

### P-1.10 引言结尾无章节导览
**症状**：第 1.5 节"论文结构"缺失或只写"第 2 章讲相关工作"。
**处方**：每章用 1 句话点明"本章解决 X 问题"。

---

## 四、第 2 章 相关工作层（4 类）

### P-2.1 相关工作写成"知识科普"
**症状**：花 2 页讲 CNN/LSTM 数学公式。
**处方**：相关工作应聚焦"本领域工作 + 与本文方法的对比"，不重复教科书内容。

### P-2.2 相关工作缺少对比表
**症状**：用纯文字描述 20+ 篇文献的优缺点。
**处方**：必须有一张"方法-数据集-性能-局限性"四列对比表（见本文 \tabref{tab:related_compare}）。

### P-2.3 引用格式不统一
**症状**：GB/T 7714、IEEE、APA 混用。
**处方**：统一用 GB/T 7714-2015（本模板 biblatex 风格）。

### P-2.4 自引过多或过少
**症状**：自引 0 次（缺）或自引 5+ 次（过）。
**参考**：硕士论文自引 1-2 次为宜。

## 五、第 3-5 章 方法层（4 类）

### P-3.1 实验无基线对比
**症状**：只报告本文方法的指标，不与 SOTA 对比。
**处方**：每章实验必须有"基线 + SOTA + 本文方法"三组对比。

### P-3.2 消融实验不完整
**症状**：只做了"加 vs 不加"一个 ablation。
**处方**：复杂方法必须有 3-5 组消融（如本文：通道宽度、窗口长度、SE 模块、量化方案）。

### P-3.3 无统计显著性检验
**症状**：A 模型 0.8340，B 模型 0.8337，结论"A 优于 B"。
**处方**：对多次运行（≥ 5 次）取均值 ± 标准差，或做配对 t 检验。

### P-3.4 复现性不足
**症状**：报告 "0.8340" 但不说随机种子、硬件、超参。
**处方**：必须有"实验设置"小节，明确：随机种子、GPU 型号、训练 epoch、batch size、学习率、数据划分比例。

## 六、图表公式层（3 类）

### P-4.1 图编号/引用错误
**症状**：图 3-2 写成图 3.2；图未引用；图被引用但未在正文中出现。
**处方**：
- 编号格式统一：`图 3-1`、`图 3-2`（章-序号）
- 每个图必须在正文中用 `\figref{}` 引用
- 引用位置应在图出现的前 1-2 段

### P-4.2 表头/表注不规范
**症状**：表头无单位；表注缺失。
**处方**：
- 表头遵循"量 / 单位"格式，如 "Macro-F1 / %"
- 表注用 `\tnote{}` 说明缩写、统计方法
- 三线表（`\toprule` `\midrule` `\bottomrule`），禁竖线

### P-4.3 公式未编号或编号混乱
**症状**：关键公式未编号；或公式编号跨章不连续。
**处方**：
- 重要公式必须用 `equation` 环境编号
- 引用格式：`\eqref{eq:xxx}`，如"见式 (\ref{eq:loss})"

## 七、写作与排版层（3 类）

### P-5.1 长句、被动语态、口语化
**症状**："我们这个方法呢，主要是通过将那个特征做一些处理，然后再..."
**处方**：
- 句子 ≤ 50 字
- 避免"我们认为"、"个人觉得"
- 数学/算法描述用"本文提出/设计/采用"

### P-5.2 章节标题层级混乱
**症状**：三级标题直接跳到五级；同级标题句式不平行。
**处方**：
- 平行标题用同种句式，如 "TCN 架构 → SE 注意力 → 融合方案"
- 数字 + 动词 + 名词的统一结构

### P-5.3 致谢写成感情散文
**症状**：致谢 1 页 +。
**处方**：致谢 200-400 字，感谢导师、家人、同学、项目基金即可。

---

## 八、参考文献层（2 类）

### P-6.1 参考文献过少或过旧
**症状**：硕士论文 15 篇参考文献；或全是 2010 年前文献。
**参考标准**：硕士论文 40-60 篇为宜，其中近 5 年文献 ≥ 60%。

### P-6.2 会议期刊混淆
**症状**：把 arXiv 预印本当正式发表；或会议论文标 "Journal of..."。
**处方**：
- 严格区分 [J] 期刊 / [C] 会议 / [D] 学位论文 / [R] 报告 / [EB/OL] 网络
- arXiv 必须标注 "[EB/OL]" 或 "[Preprint]"

---

## 九、答辩准备层（2 类）

### P-7.1 PPT 与论文不一致
**症状**：PPT 写"F1=0.85"，论文写"0.8340"。
**处方**：PPT 与论文用同一份实验日志，答辩前最后一周集中核对。

### P-7.2 不能回答核心问题
**高频评委问题预案**：
| 评委可能问 | 建议回答 |
|---|---|
| "为什么不用更长的窗口?" | w=8 是 Pareto 拐点；附消融数据 |
| "Transformer 真的不如 TCN?" | 在该 8 步序列下是的；附对比表 |
| "INT8 量化误差多大?" | 11 层 SNR ≥ 38dB；附逐层分析 |
| "实际工控场景能用吗?" | 第 5 章 MCU 实测，0.47ms @ Cortex-M4 |

| 维度 | 分值 | 扣分项 |
|---|---|---|
| 选题意义 | 1.0 | 无应用场景/无明确问题 |
| 创新点 | 2.0 | 量化不足 / 无对应章节 |
| 文献综述 | 1.0 | 堆砌无评价 / 缺对比表 |
| 方法合理性 | 2.0 | 实验设计不完整 |
| 实验与结果 | 2.0 | 无消融 / 无显著性 |
| 写作规范 | 1.0 | 长句/口语化/编号乱 |
| 图表质量 | 0.5 | 不规范 / 不引用 |
| 参考文献 | 0.5 | 格式乱 / 过少 |
| **合计** | **10.0** | |
