> 2. 培训学生避免常见错误
> 3. 作为课堂讨论素材

## 使用方法

### 🎓 老师培训用法

**Step 1**：把 `case1-abstract.md` 发给新助教，让 TA 读"学生初稿"段落。

**Step 2**：让 TA 按 `student-pitfalls.md` 23 类逐项对照，找出问题。

**Step 3**：对比"老师改写示范"段落，看 TA 是否漏掉关键问题。

**Step 4**：让 TA 模仿"评分"和"老师批注"段落，给出独立评价。

### 🎓 课堂讨论用法

**本科生教学**：
- 把"学生初稿"打印发给学生
- 让学生 5 分钟内找出所有错误
- 全班讨论"为什么这是错误"
- 老师揭晓"老师改写示范"

**研究生培养**：
- 把"学生初稿"+"合格版"对比
- 让学生独立写出第 4 个创新点的"合格版"
- 互评打分

### 🎓 学生自查用法

- 提交论文前，对照 3 个案例的"问题清单"自查
- 如果你的论文同时犯了 3 个案例的所有错误，建议大改

| 问题类型 | 案例 #1 | 案例 #2 | 案例 #3 | 出现次数 |

| 创新点无对应章节 | | ✓ | | 1 |

| 无基线对比 | | | ✓ | 1 |
| 无统计显著性 | | | ✓ | 1 |
| 复现性差 | | | ✓ | 1 |
