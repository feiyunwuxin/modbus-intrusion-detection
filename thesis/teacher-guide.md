# 教师使用说明

## 模板文件结构

```
thesis/
├── main.tex                 # 主文件（含 \pitfall/\todo/\grade 宏定义）
├── student-pitfalls.md      # 23 类学生常犯错误清单（评阅对照表）
├── teacher-guide.md         # 本文件
├── README.md                # 编译说明
├── chapters/                # 章节文件
│   ├── cover.tex            # 封面
│   ├── declaration.tex      # 诚信声明
│   ├── abstract_zh.tex      # 中文摘要
│   ├── abstract_en.tex      # 英文摘要
│   ├── chapter1_diagnostic.tex  # ★ 第 1 章（教学版，含 6 处诊断标注）
│   ├── chapter2.tex         # 第 2 章（占位）
│   ├── chapter3.tex         # 第 3 章（占位）
│   ├── chapter4.tex         # 第 4 章（占位）
│   ├── chapter5.tex         # 第 5 章（占位）
│   ├── chapter6.tex         # 第 6 章（占位）
│   ├── acknowledgment.tex   # 致谢
│   ├── publications.tex     # 科研成果
│   └── appendix_a.tex       # 附录
├── figures/                 # 图片
├── tables/                  # 表格
├── code/                    # 代码附录
└── references/refs.bib      # 参考文献数据库
```

## 三个核心宏命令

### 1. `\pitfall{编号}{描述}` — 学生常犯错误

红色警示框，列出该位置学生最常犯的错误。**草稿版显示，最终版自动隐藏。**

```latex
\pitfall{P-1.4}{学生常写成"本文提出了一种新方法"——必须每个创新点都有
可量化的指标提升。}
```

**编号规则**：`P-X.Y` 对应 `student-pitfalls.md` 中的 `P-X.Y` 条目。

### 2. `\todo[负责人]{描述}` — 待补充内容

黄色待办框，提醒学生此处需要补充内容。

```latex
\todo[学生]{补充 3.3 节的 5 折交叉验证结果}
```

### 3. `\grade[等级]{评语}` — 老师评分批注

蓝色评分框，**默认不显示**，老师评阅时手动启用。

### 4. `\good{描述}` — 优秀示例标记

绿色文字，标出"应当这样写"的范例。

## 编译模式

```latex
% main.tex 第 16 行
\newif\iffinal
\finalfalse   % 草稿模式：显示所有警示
```

**老师评阅流程**：
1. 学生提交时 `\finalfalse`（带警示的"学生版"）
2. 老师按 `student-pitfalls.md` 23 类逐项对照评阅
3. 学生修改完 → 改为 `\finaltrue` → 输出"最终版"（干净版本）

## 快速使用

### 场景 1：老师想"看学生哪里会犯错"

直接编译 `main.tex`（默认 `\finalfalse`），所有 `\pitfall{}` 都会以红色框显示。

### 场景 2：老师想"对照评阅学生初稿"

打开 `student-pitfalls.md`，按 23 类逐项检查学生论文：
- 摘要是否数据有出处？→ P-1.1
- 创新点是否量化？→ P-1.4
- 文献综述是否堆砌？→ P-1.8
- 实验是否有消融？→ P-3.2
- ……

### 场景 3：学生想"自查"

将 `\finaltrue` 改为 `\finalfalse`，重新编译，对照红色框检查自己是否犯了该错误。

### 场景 4：答辩前最终版

确认所有 `\pitfall{}` 的问题已解决，将 `\finalfalse` 改为 `\finaltrue`，得到干净版。

## 添加自定义诊断标记

老师可在任何位置插入自定义诊断：

```latex
\pitfall{自定义-001}{学生此处缺少对照实验，请补充 3 个 SOTA 方法对比}
\todo[学生]{补充图 4-7 的消融曲线}
\grade[C]{方法论合理，但实验规模偏小，建议补充 5 折交叉验证}
```

## 23 类错误速查

详见 `student-pitfalls.md`，按章节组织：

| 类别 | 数量 | 难度 |
|---|---|---|
| 整体框架 | 5 | 高 |
| 摘要目录 | 4 | 中 |
| 第 1 章绪论 | 6 | 中 |
| 第 2 章相关工作 | 4 | 中 |
| 第 3-5 章方法 | 4 | 高 |
| 图表公式 | 3 | 低 |
| 写作排版 | 3 | 中 |
| 参考文献 | 2 | 低 |
| 答辩准备 | 2 | 高 |

**最易扣分 TOP 5**：
1. P-1.4 创新点无量化数据（-2 分）
2. P-3.2 消融实验不完整（-1.5 分）
3. P-3.1 无基线对比（-1.5 分）
4. P-1.8 文献综述堆砌（-1 分）
5. P-3.3 无统计显著性检验（-1 分）
