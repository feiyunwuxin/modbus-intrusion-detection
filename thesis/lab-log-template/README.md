# 实验日志模板

> **目标**：保证实验可复现，3 个月后能根据日志 + 代码 1:1 重现任一结果。
> **配套模板**：
> - `../proposal-template/` — 开题报告
> - `../main.tex` — 论文 LaTeX 模板
> - `../word-template/thesis-template.docx` — 论文 Word 模板

---

## 快速开始

### 方法 A：使用 Excel 记录表

1. 打开 `lab-log-template.xlsx`
2. 在"实验记录"Sheet 追加新行，每天 1-5 个实验
3. 每周日填写"跨周对比"Sheet
4. 每月末用"12 类错误对照"Sheet 自检

### 方法 B：使用 Markdown 详细日志

1. 复制 `lab-log.md` 为 `lab-log-2026-09.md`（按月命名）
2. 每天 1 个"8 字段日志"
3. 配合 Excel 记录表，MD 写详细，Excel 写数据

## 8 字段详细日志（每日必填）

| # | 字段 | 字数 | 说明 |
|---|---|---|---|
| 1 | 基本信息 | 3 项 | 日期 / 研究员 / 阶段 |
| 2 | 今日目标 | 1-2 句 | 1-2 个可验证子目标 |
| 3 | 环境与代码 | 1 表 | Python / 框架 / GPU / commit |
| 4 | 数据 | 1 表 | 数据集 / 划分 / 类别分布 |
| 5 | 模型与超参 | 全列 | 所有超参与值 |
| 6 | 结果 | 1 表 | 成功 + 失败指标 |
| 7 | 分析与结论 | 3-5 句 | 观察 + 结论 + 下一步 |
| 8 | 复现性检查 | 7 项 | □/☑ 清单 |

## 12 类日志错误（速查）

| 编号 | 类别 | 错误 | 严重度 |
