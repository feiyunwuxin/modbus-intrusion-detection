# Word 配置指南（5-10 分钟完成）

> 本指南基于 Word 2016+ / Word 365，其他版本操作类似。
> 适用对象：需要从零配置硕士论文 Word 模板的老师/学生。

---

## Step 1：页面设置

**操作路径**：`布局` → `页面设置` 区域 → 点击右下角小箭头

| 项目 | 设置值 | 说明 |
|---|---|---|
| 纸张大小 | A4 (21 × 29.7 cm) | |
| 方向 | 纵向 | |
| 上边距 | 2.5 cm | |
| 下边距 | 2.5 cm | |
| 左边距 | 2.5 cm | |
| 右边距 | 2.5 cm | |
| 装订线 | 0.5 cm（左侧） | |
| 页眉 | 1.5 cm | |
| 页脚 | 1.75 cm | |

**多倍行距**：`布局` → 右下角小箭头 → `文档网格` 选项卡 →
"指定行和字符网格" → 字符数 × 行数设为合适值。

## Step 2：样式定义

**操作路径**：`开始` → `样式` 区域 → 点击右下角小箭头打开样式窗格

按以下顺序创建/修改样式：

### 2.1 标题样式

| 样式名 | 字体（中/英） | 字号 | 加粗 | 对齐 | 段前/段后 |
|---|---|---|---|---|---|
| 标题 1（章） | 黑体/Times New Roman | 二号 (22pt) | 是 | 居中 | 24pt/18pt |
| 标题 2（节） | 黑体/Times New Roman | 三号 (16pt) | 是 | 左对齐 | 12pt/6pt |
| 标题 3（小节） | 黑体/Times New Roman | 小三 (15pt) | 是 | 左对齐 | 6pt/3pt |
| 标题 4 | 黑体/Times New Roman | 四号 (14pt) | 是 | 左对齐 | 3pt/3pt |

**操作步骤**：
1. 右键"标题 1" → "修改"
2. 设置字体、字号、加粗、对齐
3. 点击左下角"格式" → "段落" 设置段前/段后
4. 重复以上步骤修改标题 2、3、4

### 2.2 正文样式

| 样式名 | 字体（中/英） | 字号 | 行距 | 首行缩进 |
|---|---|---|---|---|
| 正文 | 宋体/Times New Roman | 小四 (12pt) | 1.5 倍 | 2 字符 |

### 2.3 自定义诊断样式

**关键步骤**：建立与 LaTeX `\pitfall{}` 等价的 Word 样式。

#### 2.3.1 创建"学生常见错误"样式（红框）

1. `开始` → 样式窗格 → `新建样式`
2. 名称：**学生常见错误**
3. 基准：正文
4. 字体：楷体 / 小四
5. 边框：红色 1.5pt 边框
6. 底纹：浅红 RGB(255, 235, 235)
7. 段落：左缩进 1 字符，段前 6pt，段后 6pt
8. 点击"格式" → "快捷键" → 设为 Alt+P
9. 确定

#### 2.3.2 创建"待补充内容"样式（黄框）

类似步骤：
- 名称：**待补充内容**
- 字体：楷体 / 小四
- 边框：橙色 1.5pt
- 底纹：浅黄 RGB(255, 250, 205)
- 快捷键：Alt+T

#### 2.3.3 创建"优秀示例"样式（绿框）

- 名称：**优秀示例**
- 字体：楷体 / 小四
- 不加边框，仅加绿色下划线
- 字色：绿色 RGB(0, 128, 0)
- 快捷键：Alt+G

#### 2.3.4 创建"老师评语"样式（蓝框）

- 名称：**老师评语**
- 字体：楷体 / 小四
- 边框：蓝色 1.5pt
- 底纹：浅蓝 RGB(235, 245, 255)
- 快捷键：Alt+C

## Step 3：页眉页脚

**操作路径**：`插入` → `页眉` / `页脚`

### 3.1 页眉

- 奇数页：显示**章标题**（用域代码 `STYLEREF "标题 1" \* MERGEFORMAT`）
- 偶数页：显示**论文标题**（手工输入）
- 字号：小五号
- 字体：宋体
- 边框：底部 0.5pt 单线

**插入域代码**：
1. 光标放在奇数页页眉
2. `插入` → `文档部件` → `域`
3. 类别选"链接和引用"
4. 域名选"StyleRef"
5. 样式名选"标题 1"

### 3.2 页脚（页码）

- 前置部分（摘要/目录）：罗马数字 I, II, III
- 正文及之后：阿拉伯数字 1, 2, 3
- 位置：页面底端居中
- 字号：小五号 Times New Roman

**分节符设置**：
1. 摘要前 → 插入分节符（"布局" → "分隔符" → "下一页"）
2. 摘要前节：页码格式选"罗马数字"，起始 I
3. 第 1 章前：插入分节符
4. 第 1 章节：页码格式选"阿拉伯数字"，起始 1
5. 取消"链接到前一节"

## Step 4：多级编号

**操作路径**：`开始` → `段落` → `多级列表` → `定义新的多级列表`

### 设置 4 级编号

| 级别 | 编号格式 | 应用于 |
|---|---|---|
| 1 | 第 1 章 | 标题 1 |
| 2 | 1.1 | 标题 2 |
| 3 | 1.1.1 | 标题 3 |
| 4 | (1) | 标题 4 |

**关键设置**：
- 起始编号：1
- 每级缩进 0.74 cm
- 编号与文字间距 1 字符

## Step 5：交叉引用与题注

### 5.1 图题注

1. 插入图片
2. 右键图片 → "插入题注" → "新建标签" → "图"
3. 题注格式：图 1-1  Title
4. 位置：图片下方

**引用图**：光标放在正文 → `引用` → `交叉引用` → "图" → 选具体编号

### 5.2 表题注

类似步骤，标签设为"表"，位置在表格上方。

### 5.3 公式编号

1. 插入公式
2. 选中公式 → `引用` → `插入题注` → 标签 "公式"
3. 编号格式：式 (1-1)

## Step 6：参考文献

### 方案 A：使用 Zotero / EndNote（推荐）

1. 安装 Zotero（免费）
2. Word 插件：`Zotero Word for Mac/Win`
3. 在 Zotero 中管理文献
4. Word 中点"Add/Edit Citation"插入
5. 点"Insert Bibliography"生成参考文献列表
6. 样式选 GB/T 7714

### 方案 B：手工插入

参考 `Citation_Guide.md`，按 GB/T 7714-2015 格式手工插入。

### 方案 C：使用 Mendeley

类似 Zotero，免费，支持 GB/T 7714 样式。

## Step 7：导入 VBA 宏

### 7.1 打开 VBA 编辑器

按 `Alt + F11` 打开 Microsoft Visual Basic for Applications。

### 7.2 导入宏文件

1. `文件` → `导入文件`
2. 选择 `vba/ThesisTemplate.bas`
3. 看到模块出现在左侧"模块"下

### 7.3 使用宏

按 `Alt + F8` 打开"宏"对话框 → 选中 `InsertPitfall` → `运行`

| 宏名 | 快捷键（可自定义） | 效果 |
|---|---|---|
| InsertPitfall | Alt+Shift+P | 插入红色错误警示框 |
| InsertTodo | Alt+Shift+T | 插入黄色待办框 |
| InsertGood | Alt+Shift+G | 插入绿色优秀示例 |
| InsertGrade | Alt+Shift+C | 插入蓝色老师评语 |
| TogglePitfall | Ctrl+Shift+H | 显示/隐藏所有诊断框 |

## Step 8：保存模板

1. `文件` → `另存为`
2. 文件类型选"Word 模板 (\*.dotx)"
3. 命名为 `ThesisTemplate.dotx`
4. 保存到 `C:\Users\你的用户名\Documents\自定义 Office 模板`

下次新建 Word 文档时，可在"个人"选项卡找到此模板。

## 常见问题

### Q1: 章节编号错了？
A: 检查"多级列表"是否正确链接到标题样式。修改标题样式不会自动更新编号。

### Q2: 页码从摘要就开始了 1？
A: 需要在第 1 章前插入分节符，并取消"链接到前一节"。

### Q3: 图表编号混乱？
A: 使用"插入题注"而非手动输入"图 1-1"。

### Q4: VBA 宏被禁用？
A: `文件` → `选项` → `信任中心` → `信任中心设置` → `宏设置` 选"启用所有宏"。

### Q5: Word 和 LaTeX 双模板哪个好？
A: Word 适合**协作修改、最终打印**；LaTeX 适合**公式密集、自动排版**。本课题公式与代码多，建议 LaTeX 为主，Word 用于协作。
