## 五、章节编号

### 5.1 阿拉伯数字编号（标准格式）

```
第 1 章  绪论                     ← 章 (中文数字 + 章)
  1.1   研究背景与意义             ← 节 (阿拉伯)
    1.1.1  国内研究现状            ← 小节
    1.1.2  国外研究现状
  1.2   研究内容
第 2 章  相关理论与技术基础
  2.1   SCADA 入侵检测任务定义
  2.2   时序卷积网络（TCN）
    2.2.1  因果卷积
    2.2.2  膨胀卷积
第 3 章  SCADA 协议特征工程
  ...
参考文献
致谢
附录 A  TCN V19 MCU 部署代码
```

### 5.2 图/表/公式编号

```
图 1-1   ××××
图 3-2   ××××
表 4-1   ××××
表 5-3   ××××
式 (2-1)
式 (3-5)
```

格式：`图 X-Y` 中 X=章号，Y=章内序号。

## 六、诊断框样式

| 样式名 | 字体 | 边框 | 底纹 | 用途 |
|---|---|---|---|---|
| 学生常见错误 | 楷体小四 | 红色 1.5pt | 浅红 #FFEBEB | `\pitfall{}` |
| 待补充内容 | 楷体小四 | 橙色 1.5pt | 浅黄 #FFFACD | `\todo{}` |
| 优秀示例 | 楷体小四 | 绿色虚线 | 无 | `\good{}` |
| 老师评语 | 楷体小四 | 蓝色 1.5pt | 浅蓝 #EBF5FF | `\grade{}` |

### 创建步骤（以"学生常见错误"为例）

1. `开始` → 样式窗格 → 右键 → "新建样式"
2. 名称：`学生常见错误`
3. 基准：正文
4. 字体格式：
   - 中文字体：楷体
   - 西文字体：Times New Roman
   - 字号：小四
5. 段落格式：
   - 左缩进：1 字符
   - 段前/段后：6pt
   - 行距：1.5 倍
6. 边框：
   - 颜色：红色 RGB(192, 0, 0)
   - 宽度：1.5pt
   - 边框：方框
7. 底纹：
   - 颜色：浅红 RGB(255, 235, 235)
8. 快捷键：Alt+Shift+P

|---|---|

## 八、参考文献样式（GB/T 7714-2015）

### 期刊论文

```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
示例：[1] 周天逸, 李源, 吴磊. SCADA 系统综述[J]. 计算机安全, 2022, 118: 102734.
```

### 会议论文

```
[2] 作者. 题名[C]//会议名. 出版地: 出版者, 年: 起止页码.
示例：[2] Wang W. Malware traffic classification using CNN[C]//ICOIN. IEEE, 2017: 712-717.
```

### 学位论文

```
[3] 作者. 题名[D]. 保存地: 保存单位, 年.
示例：[3] 张三. 基于深度学习的入侵检测研究[D]. 北京: 清华大学, 2025.
```

### 专著

```
[4] 作者. 书名[M]. 版次. 出版地: 出版社, 年.
```

### 专利

```
[5] 申请人. 专利名称: 专利号[P]. 公开日期.
```

### 电子文献

```
[6] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

### arXiv 预印本

```
[7] 作者. arXiv:编号[Preprint]. arXiv, 年. https://arxiv.org/abs/编号
```

## 九、目录样式

### 9.1 目录层级

| 级别 | 字体 | 字号 | 缩进 |
|---|---|---|---|
| 第 1 级（章） | 黑体 | 小四 | 0 |
| 第 2 级（节） | 宋体 | 小四 | 1 字符 |
| 第 3 级（小节） | 宋体 | 小四 | 2 字符 |

### 9.2 自动生成

1. 光标放在目录起始位置
2. `引用` → `目录` → `自定义目录`
3. 显示级别：3
4. 制表符前导符：点号 ............
5. 显示页码：✓
6. 右对齐页码：✓
7. 点击"修改"分别设置各级样式
