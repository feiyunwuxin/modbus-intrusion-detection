> - `../main.tex` — 论文 LaTeX 模板

> - `../review/review-checklist.xlsx` — 论文评阅对照表
> - `../scripts/auto_grade.py` — pitfall 自动统计

---

## 快速开始

### 方法 A：使用本目录的 `.docx` 模板

1. 打开 `proposal-template.docx`（已生成，含诊断框）
2. 修改封面信息 → 删除诊断框 → 提交开题

### 方法 B：从 md 重新生成

```bash
python generate_proposal_docx.py
```

### 方法 C：直接修改 `proposal.md`

开题前 2-3 周修改，保留 `> ⚠️` 等诊断标注作为自我检查清单。
