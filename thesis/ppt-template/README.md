# 答辩 PPT 模板

> **配套**：LaTeX 论文模板 (`../main.tex`) + Word 模板 (`../word-template/`)
> **建议时长**：硕士 20-25 分钟，PPT 25-30 张
> **风格**：学术严谨 + 视觉清爽

## PPT 核心原则

### 1. 25-30 张为宜

| 数量 | 评语 |
|---|---|
| < 20 张 | 太空，评委认为"工作量不足" |
| **25-30 张** | **最佳** |
| > 40 张 | 太满，评委走神 |

### 2. 每张 ≤ 5 行文字

**黄金法则**：评委 30 秒扫一张，文字太多就直接放弃。

| 元素 | 数量建议 |
|---|---|
| 标题 | 1 行，≤ 20 字 |
| 正文要点 | 3-5 条 |
| 每条字数 | ≤ 30 字 |
| 关键数据 | 1-2 个醒目数字 |
| 图片/图表 | 1-2 个 |

### 3. 数据可视化优于表格

**反例**：
> 表 4-1 27 个模型的 Macro-F1 详细数据

**正例**：
> 横向条形图：4 个代表模型（LightGBM / CNN / BiLSTM / TCN-SE）的 F1 对比

### 4. 三大创新点各占 3-4 张

| 创新点 | 张数 |
|---|---|
| 27 维特征 | 3 张（动机 + 设计 + 实验） |
| TCN-SE | 4 张（横评 + 架构 + 消融 + 结论） |
| V19 + 混合 INT8 | 4 张（消融 + 问题 + 方案 + 部署） |

## 时间分配（25 分钟版）

| 部分 | 张数 | 时长 |
|---|---|---|
| 背景 + 文献 + 不足 | 6-7 | 5-6 min |
| 创新点（核心） | 12-13 | 12-14 min |
| 总结 + 展望 + 致谢 | 4-5 | 3-4 min |
| Q&A 缓冲 | --- | 1-2 min |

**关键**：创新点部分占总时间 50%。

## 视觉规范

### 颜色方案

```
主色：深蓝 #1F4E79（标题、强调）
辅色：橙色 #ED7D31（关键数据、强调）
背景：白色 #FFFFFF
正文：黑色 #262626
点缀：浅灰 #D9D9D9（次要信息）
```

### 字体

| 元素 | 中文字体 | 英文字体 | 字号 |
|---|---|---|---|
| 标题 | 微软雅黑 | Calibri | 28-32 pt |
| 正文要点 | 微软雅黑 | Calibri | 20-24 pt |
| 数据标注 | Arial | Calibri | 18-22 pt |
| 页码 | 微软雅黑 | Calibri | 10-12 pt |

### 图表

- 统一柱状图配色：主色 + 辅色
- 所有表格用三线表（无竖线）
- 关键数字**加粗 + 变色**（辅色）

## 与论文的差异

| 维度 | 论文 | PPT |
|---|---|---|
| 目的 | 详细论证 | 快速传达 |
| 读者 | 仔细阅读者 | 评委扫一眼 |
| 详略 | 完整 | 突出关键 |
| 公式 | 详细推导 | 只给结论 |
| 实验 | 完整数据 | 关键图表 |
| 引用 | 全文 GB/T 7714 | 仅核心文献 |
