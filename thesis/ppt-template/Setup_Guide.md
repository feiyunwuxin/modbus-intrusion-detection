# PPT 配置指南（5 分钟完成）

> PowerPoint 2016+ / Office 365，WPS 演示也适用。

---

## Step 1：幻灯片大小

**操作路径**：`设计` → `幻灯片大小` → `自定义幻灯片大小`

| 项目 | 设置值 |
|---|---|
| 宽度 | 33.867 cm |
| 高度 | 19.05 cm |
| 方向 | 横向（16:9） |

> ⚠️ 不要用 4:3（10×7.5 英寸），那是 2010 年前的标准。

---

## Step 2：母版视图

**操作路径**：`视图` → `幻灯片母版`

### 母版 1：标题页

- 背景：白色
- 中央放置标题（28-32 pt 黑体）
- 副标题（20 pt 宋体）
- 底部：作者 / 导师 / 日期（18 pt）

### 母版 2：内容页

```
┌─────────────────────────────────────┐
│  标题                                │  ← 28pt 黑体，左对齐
├─────────────────────────────────────┤
│                                     │
│  正文内容区域                        │  ← 20-24pt
│                                     │
├─────────────────────────────────────┤
│  论文标题           第 X 页 / 25    │  ← 10-12pt
└─────────────────────────────────────┘
```

- 顶部：标题占 1/8
- 中部：内容占 6/8
- 底部：页码占 1/8

### 母版 3：图表页

- 与内容页类似，但中部区域更大（无段落缩进）
- 图表居中，周围留白

### 母版 4：分隔页

- 整页彩色背景（深蓝 #1F4E79）
- 中央白色文字（章节标题）

## Step 3：颜色方案

**操作路径**：`设计` → `变体` → `颜色` → `自定义颜色`

| 名称 | RGB |
|---|---|
| 主色（深蓝） | 31, 78, 121 (#1F4E79) |
| 辅色（橙） | 237, 125, 49 (#ED7D31) |
| 背景 | 255, 255, 255 |
| 正文 | 38, 38, 38 (#262626) |
| 浅灰 | 217, 217, 217 (#D9D9D9) |
| 成功（绿） | 84, 130, 53 (#548235) |
| 警告（红） | 192, 0, 0 (#C00000) |

---

## Step 4：字体

**中文字体**：
- 标题：微软雅黑（粗体）
- 正文：微软雅黑（常规）

**英文字体**：
- 标题：Calibri（粗体）
- 正文：Calibri

> ⚠️ **不要用宋体 / Times New Roman** —— 太正式，不适合 PPT

---

## Step 5：占位符设置

**操作路径**：`视图` → `幻灯片母版` → 选中占位符 → 设置

### 标题占位符

| 项目 | 设置值 |
|---|---|
| 字体 | 微软雅黑 / 28pt |
| 颜色 | 主色（深蓝） |
| 对齐 | 左对齐 |
| 占位符大小 | 宽 28cm × 高 2cm |
| 位置 | 顶部 0.5cm |

### 内容占位符

| 项目 | 设置值 |
|---|---|
| 字体 | 微软雅黑 / 20pt |
| 颜色 | 黑色 |
| 对齐 | 左对齐 |
| 占位符大小 | 宽 28cm × 高 13cm |
| 位置 | 距顶部 3cm |
| 项目符号 | ● / ▶ / 1. / ① |

### 页码占位符

| 项目 | 设置值 |
|---|---|
| 字体 | 微软雅黑 / 10pt |
| 颜色 | 浅灰 |
| 位置 | 底部居中 |
| 格式 | "第 X 页 / 总 Y 页" |

## Step 7：演讲者视图

**操作路径**：`幻灯片放映` → `使用演讲者视图`

演讲者视图可看到：
- 当前幻灯片
- 下一张幻灯片
- 演讲者备注
- 时钟

**多屏配置**：
1. 连接投影仪
2. `Windows + P` → 扩展
3. PPT 自动识别：笔记本 = 演讲者视图，投影 = 受众视图

---

## Step 8：保存与备份

### 三重备份

1. **本地 PPTX**：`thesis-defense.pptx`（编辑用）
2. **PDF 版本**：`文件` → `另存为` → PDF（防格式错乱）
3. **放映版本**：`文件` → `另存为` → `PowerPoint Show (\*.ppsx)`

### U 盘准备

- PPTX
- PDF
- 论文 PDF
- 备用字体（嵌入字体）

**嵌入字体**：
`文件` → `选项` → `保存` → 勾选"将字体嵌入文件"

### 微信文件传输

把 PPTX 和 PDF 发到自己微信"文件传输助手"，现场用手机开热点。
