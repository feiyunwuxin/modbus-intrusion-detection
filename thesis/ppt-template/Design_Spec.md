# PPT 设计规范

## 一、颜色方案

### 主色板

```
主色：#1F4E79（深蓝）    ← 标题、强调、章节分隔
辅色：#ED7D31（橙）      ← 关键数据、突出
背景：#FFFFFF（白）       ← 内容区
正文：#262626（深灰黑）   ← 正文
```

### 辅助色

```
浅灰：#D9D9D9     ← 次要信息
深灰：#595959     ← 备注
成功：#548235（绿）← 正面对比
警告：#C00000（红）← 反面对比
```

### 配色原则

| 场景 | 配色 |
|---|---|
| 背景 | 白色 / 浅灰（绝不大面积用彩色） |
| 标题 | 深蓝（章节标题） / 黑色（小节） |
| 关键数字 | 橙色 + 加粗 |
| 表格表头 | 深蓝底 + 白字 |
| 强调框 | 橙色边框 + 浅橙底 |
| 反直觉结论 | 红色文字 |

## 二、字体规范

### 字体映射

| 元素 | 中文字体 | 英文字体 | 用途 |
|---|---|---|---|
| 章节大标题 | 微软雅黑 Bold | Calibri Bold | 章节分隔页 |
| 幻灯片标题 | 微软雅黑 Bold | Calibri Bold | 每张标题 |
| 正文要点 | 微软雅黑 | Calibri | 主体内容 |
| 数据标签 | 微软雅黑 Bold | Calibri Bold | 数字 |
| 注释 | 微软雅黑 | Calibri | 图注 |
| 代码 | Consolas | Consolas | 公式代码 |

### 字号规范

| 元素 | 字号 | 行距 |
|---|---|---|
| 章节大标题 | 40-48 pt | 1.2 倍 |
| 幻灯片标题 | 28-32 pt | 1.2 倍 |
| 正文要点 | 20-24 pt | 1.3 倍 |
| 数据标签 | 18-22 pt | 1.0 倍 |
| 图注 | 12-14 pt | 1.0 倍 |
| 页码 | 10-12 pt | 1.0 倍 |

### 字号减法

> 1 张 PPT 上字号种类 ≤ 3 种

- 标题用 28pt
- 正文用 20pt
- 数据用 22pt（**且加粗 + 变色**）

## 四、图表规范

### 4.1 表格（必须用三线表）

```
─────────────────────────
  表头1    表头2    表头3   ← 深蓝底白字
─────────────────────────
  数据1    数据2    数据3
  数据4    数据5    数据6
─────────────────────────
```

**禁止**：
- 竖线
- 斜线表头
- 多层嵌套表头

**关键数字**：
- 橙色 + 加粗
- 显著区别于其他行

### 4.2 柱状图

- 柱体颜色：主色（深蓝）
- 突出柱：辅色（橙）
- 数值标签：柱顶
- Y 轴：从 0 开始
- 网格：浅灰（淡出）

### 4.3 折线图

- 主线：实线 + 主色
- 对比线：虚线 + 辅色
- 关键点：圆点 + 加粗
- 图例：右上角

### 4.4 图片

- 统一白底 / 透明底
- 加 1px 浅灰边框
- 命名规则：fig-X-Y-描述.png

## 五、动效规范

### 5.1 推荐动效

| 元素 | 动效 | 时长 |
|---|---|---|
| 章节标题 | 淡入 | 0.3s |
| 列表要点 | 逐条出现 | 0.2s / 条 |
| 图表 | 缩放 | 0.5s |
| 关键数字 | 飞入 | 0.5s |
| 转场 | 推入 | 0.3s |

### 5.2 禁止动效

- ❌ 旋转（影响阅读）
- ❌ 弹跳（幼稚）
- ❌ 闪烁（评委走神）
- ❌ 多余的"噼里啪啦"声音

### 5.3 动效原则

> **动效服务于内容，而非炫技**
> 每张幻灯片动效 ≤ 2 种
> 总幻灯片动效 ≤ 5 种

## 六、视觉一致性

### 6.1 Logo / 校徽

- 放在标题页左下角
- 大小：3-4 cm
- 不变形、不压缩

### 6.2 配色一致性

- 全文同一指标用同色
  - 如 "Macro-F1" 全部用橙色
  - 如 "PR-AUC" 全部用主色
- 不混用多种蓝色 / 多种橙色

### 6.3 字号一致性

- 所有章节标题同字号
- 所有正文要点同字号
- 不出现"每张 PPT 标题都不一样"

### 6.4 边距一致性

- 上边距：0.5 cm
- 下边距：0.5 cm
- 左右边距：1.0 cm
- 段落间距：0.3 cm

---

## 七、可访问性

### 7.1 颜色对比度

- 正文 vs 背景：≥ 7:1（深色文字 + 白底）
- 标题 vs 背景：≥ 4.5:1

### 7.2 色盲友好

- 不仅靠颜色区分（如红/绿对比，加形状或文字）
- 关键数据用粗体或下划线补充

### 7.3 字体大小

- 最远观众（5-10m）应能看清 18pt 以上
- 关键数字 ≥ 24pt
